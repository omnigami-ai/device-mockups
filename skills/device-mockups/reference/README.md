# Ostlery reference

Ostlery is a fictional company made for omnigami's examples. `product.js` contains all product inputs.
`index.html` is the editable renderer; `looks.json` selects the four approved looks. `plans/` holds the real
capture plans. PRODUCT.md and STORY.md specify the truthful states and their placement. Assets and libraries
are local. Open through any static server (`?dir=<ID>&size=16:9` or `9:16`), or use the render command in SKILL.md.
The static server is only for local module loading; the canvas itself makes no external requests.

Round 2 additions: named capture-pixel `desktopProtection` and optional `phoneSide` in product/values;
`capture-plan.mjs` gates production capture on centring with explicit exact-log native findings;
L2's default is the selected no-actions treatment, with short line/sentence and the tighter gap.
The old action hierarchies and proposal inputs are removed. `window.template.audit()` reports fitted outside text sizes, desktop projection/
clearance and T2's slot order. It is numeric evidence, not a substitute for image review or a fresh reader.
